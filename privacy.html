Privacy Policy

Last updated: 8 November 2026 · Single-user fitness application

1. Purpose

Ultra Performance is a personal training diary and fitness planning application. Its Garmin and Oura integrations are intended to help the account holder review training sessions, sleep, heart-rate variability (HRV), resting heart rate and recovery trends. The application is presently designed for the account holder's own use.

2. Information processed

  • User-entered information: training plans, exercise sets, repetitions, weights, perceived effort, activity notes and recovery check-ins.
  • Garmin: activity summaries such as type, start time, duration, distance and available exercise metrics.
  • Oura: daily sleep and readiness information, including available HRV and resting heart rate measurements, accessed only after the user authorizes the daily permission.
  • Technical credentials: Garmin personal API credentials and Oura application secrets are managed as Cloudflare Worker secrets; temporary API access and OAuth refresh tokens are maintained in a private Cloudflare KV namespace.

3. Storage and access

Training and imported recovery records are kept in the browser's local storage on the device used. They do not automatically synchronize between devices. The Cloudflare Worker retrieves data from Garmin and Oura when the user initiates synchronization. Oura OAuth tokens and a temporary Garmin access token are held in the Worker's KV storage. The Worker access token is kept in the browser's session storage rather than committed to the public GitHub Pages source code. The application does not operate a public account directory.

4. Uses and sharing

Data is used to display training history and provide rule-based fitness and recovery recommendations. The application does not sell personal or health information or share it with advertisers. Processing necessarily involves the providers used for hosting and integration, including GitHub Pages, Cloudflare, Garmin and Oura, subject to their respective service terms and privacy practices. Hosting providers may process technical access logs.

5. Retention and deletion

Local entries remain on the device until removed using the application's reset controls or the browser's site-data controls. Disconnecting Oura in the application deletes its stored OAuth tokens from the Worker's KV store; it does not automatically erase previously imported local records. The user can revoke Oura permissions in their Oura account. Garmin credentials can be revoked or removed from Cloudflare Worker secrets. Operational logs may have different retention periods controlled by hosting providers.

6. Security and limitations

The Worker is configured to require a private access token for data operations. Credentials must not be published in GitHub repositories or shared publicly. No internet service can guarantee absolute security. As this is a personal project, it should not be used as a repository for information beyond the data necessary for the stated fitness features.

7. Contact and updates

Questions concerning this integration can be directed to the application's developer using the contact address registered in the Oura Developer Portal. This notice may be updated when data practices change.

Suomeksi — tietosuojan yhteenveto

Ultra Performance tallentaa harjoituskirjaukset selaimesi paikalliseen tallennustilaan. Garmin- ja Oura-tietoja haetaan vain käyttäjän käynnistämällä synkronoinnilla. Ouran unta ja palautumista koskeviin tietoihin pyydetään daily-oikeus. Kirjautumistunnukset ja OAuth-tunnisteet käsitellään Cloudflare-välipalvelussa, eikä niitä julkaista GitHubissa. Tietoja ei myydä eikä luovuteta mainostajille. Ouran yhteyden voi katkaista sovelluksesta ja paikalliset tiedot poistaa sovelluksesta tai selaimesta.
