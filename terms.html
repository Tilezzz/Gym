1. Service

Ultra Performance is a personal-use fitness planning and activity logging application, hosted as a website on GitHub Pages. Optional integrations retrieve activity information from Garmin and daily recovery and sleep information from Oura through a separate Cloudflare Worker.

2. Intended use

The application is provided for tracking and general fitness guidance. Training suggestions are informational only and are not medical advice, diagnosis, or treatment. Users remain responsible for exercise selection, training intensity and consulting a qualified professional when appropriate, particularly in the presence of symptoms, injury or illness.

3. Accounts and data permissions

Connecting Garmin or Oura requires the user's own account and authorization. Oura access requests only the data categories required for the active integration. Users must follow the applicable Garmin, Oura, Cloudflare and GitHub terms. Users should not publish credentials or attempt to access another person's data.

4. Availability and accuracy

The application is provided as an evolving personal project without any guarantee of uninterrupted availability or the accuracy of third-party measurements and derived training recommendations. External APIs, quotas and integrations may change or stop working. Users are responsible for keeping copies of data they wish to retain.

5. Stopping use

Users can stop using the application at any time, remove locally stored information, and disconnect Oura authorization. Revoking access with the original provider may be required to fully terminate provider-side permissions. See the Privacy Policy for data practices.

6. Contact and changes

For questions about this personal integration, use the developer contact registered with the Oura Developer Portal. These terms may be revised as the application's functionality changes.
