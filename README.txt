ULTRA GYM 4.0 – PERFORMANCE TRAINING

Asennus:
1. Vie hakemiston sisältö GitHub Pages -repositoryyn, korvaa vanhat tiedostot.
2. Säilytä sama verkko-osoite ja GitHub Pagesin julkaisupolku.
3. Päivitä Safari-sivu tarvittaessa. PWA:n välimuisti vaihtuu versioon ultra-gym-v4.
4. Ota vanhasta sovelluksesta Asetukset > Vie kaikki (JSON) varmuuskopio ennen korvausta.

V4:
- Musta / gunmetal / deep-green premium UI
- Progressiivinen RIR-ohjaus (3 -> 2 -> 1 suosituksena)
- Kuormitustilan valinta: normaali, kuormittunut, juoksukuorma
- Joustava 1-, 2- ja 3-jako sekä 30/45/60/75 min aikabudjetti
- Ajankäytön arvio, jossa pääliikkeiden lepoajat eivät keinotekoisesti lyhene
- Double progression -ehdotukset edellisten todellisten sarjojen perusteella
- Toteutunut volyymi lihasryhmittäin viimeiseltä 7 vuorokaudelta
- 3 mesosyklin automaattinen 6/8/10/12 viikon ohjelmakierto
- Työsarjojen kirjaus, kehityskäyrät, historia, CSV/JSON-vienti

Tietojen tallennus: localStorage, avain ultragym-data-v1. V3:n historia ja asetukset säilyvät
saman verkkotunnuksen ja selainsäilön alla. Offline-välimuisti on toteutettu PWA:lla.
Treenidata ei synkronoidu selainten tai laitteiden välillä.

Ohjelman määräajat ovat kalenteripohjaisia; kovan kuormituksen kevennys on käyttäjän päätös.
Harjoittelun tuki, ei yksilöllinen lääketieteellinen ohje.
